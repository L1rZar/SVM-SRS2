# СРС № 2 — Численные методы решения нелинейных уравнений

Решение нелинейного уравнения x³ + 2x − 5 = 0 на интервале [1; 2].

## Реализованные методы

- Метод бисекции
- Метод хорд
- Метод Ньютона (x₀ = 1,5 и x₀ = 1,1)
- Метод простой итерации (x₀ = 1,5 и x₀ = 1,1)

## Точности

- ε = 10⁻³
- ε = 10⁻⁵

## Проверка

Результаты сверены с библиотечными функциями SciPy:
- `scipy.optimize.bisect`
- `scipy.optimize.newton`
- `scipy.optimize.root_scalar`
